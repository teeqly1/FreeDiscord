> **FreeDiscord** — профессиональный консольный бустер для обхода блокировок Discord на территории РФ. Полностью восстанавливает доступ к официальному сайту, десктопному приложению, обмену медиафайлами (CDN) и голосовым каналам (WebRTC / UDP).

---

## 🌟 Возможности

- **Максимально эффективный алгоритм обхода (WinWS + Zapret Engine)**:
  - Обход блокировок ТСПУ РКН на уровне сетевых пакетов.
  - **Голосовые каналы (Voice Channels)**: полная поддержка перехвата и десинхронизации UDP WebRTC и STUN пакетов (порты 50000–50100, 19294–19344).
- **Встроенный консольный движок PyUI**:
  - Строгий презентабельный дизайн без эмодзи.
  - Нативная поддержка VT100 / Virtual Terminal Processing в Windows (TrueColor 24-bit).
  - Градиентный логотип и четкие моноширинные панели.
- **Авто-установщик зависимостей (`installer.py`)**:
  - Проверяет наличие всех необходимых библиотек (`pystyle`, `psutil`, `requests`) и автоматически доустанавливает недостающие.
- **Поддержка Git и npm**:
  - Полная интеграция с npm (`npm start`, `npm run setup`, `npm run build`, `npm test`).
  - Готовые конфигурации `.gitignore` и `.gitattributes` для публикации на GitHub.
- **Глубокая настройка параметров**:
  - Выбор сигнатур Fake-TLS (`google.com`, `sferum.ru`, `max.ru`, `4pda.to` и др.).
  - Выбор сигнатур Fake-QUIC (`google.com`, `rutube.ru`, `steamcommunity.com`).
  - Режимы десинхронизации (`fake,fakedsplit`, `split2`, `disorder2`), повторы (Repeats) и TCP Fooling.
- **Альтернативный локальный Python Proxy**:
  - Встроенный TLS SNI-сплиттер, работающий без прав Администратора.
- **Фоновая служба Windows**:
  - Установка в качестве системной службы Windows для фоновой работы после перезагрузки ПК.

## 🚀 Быстрый запуск

### Вариант 1 (В один клик через bat):
Дважды нажмите на **`run.bat`** — скрипт запросит права Администратора (UAC) и запустит приложение.

### Вариант 2 (Через npm):
```bash
# Установка зависимостей и запуск
npm run setup
npm start
```

### Вариант 3 (Через Python и Git):
```bash
# Клонирование репозитория
git clone https://github.com/your-username/FreeDiscord.git
cd FreeDiscord

# Запуск авто-установщика и программы
python src/installer.py
python src/main.py
```

## ❓ Вопросы и Решение Проблем (FAQ)

### 1. Вечное "Подключение к голосовому каналу" (RTC Connecting)
Для перехвата UDP-трафика голосовых каналов Discord требуются права Администратора:
- Нажмите **`[U]`** в меню для перезапуска с правами Администратора, либо запускайте через **`run.bat`**.
- Используйте стратегию по умолчанию `[1] General ALT`.

### 2. Сайт открывается, но аватарки или картинки не прогружаются
Нажмите **`[5]`** и выберите профиль `Fake TLS Auto Alt` (для Ростелеком / Дом.ру) или настройте Fake TLS сигнатуру в пункте **`[6]`**.
